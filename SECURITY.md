## Reporting a Vulnerability

The FamilyBoard team takes the security of personal family data seriously.

If you discover a security vulnerability, please report it privately rather than opening a public issue.

### How to Report:
- **Email:** `scottrmhardie@gmail.com`
- **Subject:** `[SECURITY] FamilyBoard Vulnerability Report`
- **Details:** Please provide a detailed description of the vulnerability, steps to reproduce, potential impact, and any proof-of-concept code.

### Response Timeline:
- **Initial Acknowledgment:** Within 48 hours.
- **Status Update:** Within 7 days with validation and remediation timeline.
- **Public Disclosure:** Coordinated after a security fix has been released.

For full architectural details on credential isolation, sandboxing, and defenses, see [docs/SECURITY.md](docs/SECURITY.md) and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
